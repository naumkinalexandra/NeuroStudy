# NeuroStudy

Учебный проект для планирования нагрузки и дедлайнов студентов. Приложение позволяет добавлять задания, рассчитывать условный приоритет, сортировать задачи и отмечать их выполненными.

## Возможности

- Добавление задачи: название, дисциплина, дедлайн, оценка времени и сложность.
- Расчёт приоритета по понятной эвристике.
- Сортировка активных задач по убыванию приоритета.
- Сохранение данных в `tasks.json`.
- Проверка некорректного ввода.
- Отметка задач выполненными.

## Требования

- Python 3.10 или новее.
- Сторонние библиотеки не нужны.

## Запуск в Visual Studio Code

1. Распакуйте архив `NeuroStudy.zip`.
2. Откройте в VS Code папку `NeuroStudy` через **File → Open Folder**.
3. При необходимости установите расширение **Python** от Microsoft.
4. Откройте файл `neurostudy.py`.
5. Откройте терминал (**Terminal → New Terminal**).
6. Запустите:

   ```bash
   python neurostudy.py
   ```

   Если команда `python` не работает, попробуйте `py neurostudy.py` в Windows или `python3 neurostudy.py` в macOS/Linux.

## Как пользоваться

В меню выберите:
1. Добавить задачу.
2. Показать план.
3. Отметить задачу выполненной.
4. Выход.

Даты вводятся в формате `ГГГГ-ММ-ДД`, например `2026-11-05`. После первого сохранения рядом с программой появится `tasks.json`.

## Формула приоритета

Пусть `d` — количество дней до дедлайна, `c` — сложность от 1 до 5, `h` — ожидаемое время выполнения в часах:

`P = 10 / (max(d, 0) + 1) + 0.8 * c + 0.3 * h`

Это учебная эвристика для демонстрации алгоритма, а не доказанная модель продуктивности. Коэффициенты можно менять и оценивать на тестировании.
